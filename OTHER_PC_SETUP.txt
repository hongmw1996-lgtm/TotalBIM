TotalBIM - 다른 컴퓨터에서 작업하는 방법

1. 필수 프로그램 설치

- Git for Windows
  https://git-scm.com/download/win

- Node.js LTS
  https://nodejs.org/

2. 프로젝트 다운로드

PowerShell 또는 터미널을 열고 아래 명령을 실행합니다.

git clone https://github.com/hongmw1996-lgtm/TotalBIM.git
cd TotalBIM

3. 패키지 설치

npm install

4. 개발 서버 실행

npm run dev

브라우저에서 아래 주소를 엽니다.

http://localhost:3000

5. 수정 후 GitHub에 다시 올리기

git add .
git commit -m "수정 내용"
git push

6. 환경변수 주의사항

.env.local, .env.vercel.local, .env.worker.local 같은 파일은 보안 때문에 GitHub에 올리지 않습니다.
다른 컴퓨터에서도 같은 API, DB, Vercel, Google Drive, 저장소 기능을 쓰려면 기존 컴퓨터의 환경변수 내용을 새 컴퓨터에 직접 만들어야 합니다.

예시:

.env.local
