# TotalBIM

Next.js app for the IFC BIM viewer workspace.

## Local setup

```powershell
git clone https://github.com/hongmw1996-lgtm/TotalBIM.git
cd TotalBIM
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```powershell
npm run build
```

## Deployment

The Vercel project is linked to `ifc-upload-bim-viewer`.
Production URL:

```text
https://ifc-upload-bim-viewer.vercel.app
```

Do not commit local build output, environment files, uploaded IFC files, or Vercel auth files.
